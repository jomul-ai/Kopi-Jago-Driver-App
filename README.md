# Kopi Jago Driver – Route Optimization App

## Overview
Kopi Jago Driver is a Flask-based web application that helps coffee drivers plan efficient and profitable selling routes in Jakarta. The system applies distance calculation and optimization algorithms to maximize revenue within limited working hours.

This project is developed as an algorithm and optimization case study.

---

## Key Features
- Automatic GPS-based starting location
- Route optimization based on distance and demand
- Revenue estimation for each route
- Interactive route visualization using Folium
- Minimum Spanning Tree analysis (Prim’s Algorithm)
- Google Maps navigation support

---

## Algorithms Used
- **Haversine Formula** for distance calculation
- **Greedy Algorithm** for route selection
- **Prim’s Algorithm** for Minimum Spanning Tree analysis

---
## Running the Program
- Open in browser: http://127.0.0.1:5000
- Location access must be enabled.

---

## Output
- Optimized selling route
- Total travel distance
- Estimated total revenue
- Interactive route map
